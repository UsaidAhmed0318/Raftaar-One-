# Images
This folder is ready for licensed merchant/product photography. No competitor images are copied.
The current interface deliberately uses React Icons and CSS 3D-style decoration, not AI-generated icons.
The app icon is in app/icon.svg. Social share artwork is rendered as PNG by app/opengraph-image.tsx.
Before adding uploads, implement a private upload bucket, MIME/size checks, EXIF stripping, malware checks, rights review and signed upload URLs.
Do not publish CNIC or driver licence documents in this public folder.
